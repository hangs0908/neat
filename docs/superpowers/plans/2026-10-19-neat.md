# Neat 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** macOS 27용 Thaw를 기반으로 개인용 Neat 앱을 구성한다.

**Architecture:** `upstream/`의 Thaw 커밋 c0afbdbf045eca8b1d276e7493272ee07c3996be를 유지하며 사용자 접점만 최소화한다. 기존 레이아웃, 캡처, 원본 클릭, 화면별 제어를 재사용한다. Neat 전용 기본값과 유휴 판정은 독립적으로 검증한다.

**Tech Stack:** Swift, SwiftUI, AppKit, ServiceManagement, Thaw의 기존 Swift 패키지 및 Xcode 프로젝트.

**Spec:** `docs/superpowers/specs/2026-10-19-neat-design.md`

## 공통 제약

- 현재 macOS 27.0.1, arm64 기준. 사용자 설정이나 기존 Thaw 설치를 덮어쓰지 않는다.
- Neat은 독립 bundle ID를 사용한다. GPL-3.0 및 원본 저작권 유지.
- 새 코드의 주석·사용자 문구·문서는 한국어, 함수와 변수는 camelCase.
- 외부 배포와 공증은 제외. 앱 빌드에는 전체 Xcode가 필요하다.

## 리뷰 초점

- 재시작 후 로그인 시 실행을 사용자가 껐으면 다시 켜지지 않아야 한다.
- 바 또는 원본 메뉴를 사용하는 중 자동 닫기가 발생하지 않아야 한다.
- 자동 닫기 옵션과 무관하게 바깥 클릭은 바를 닫아야 한다.
- 새 화면도 별도 바와 동일 자동 닫기 설정을 사용해야 한다.
- Neat의 helper, URL, 업데이트 및 설정 저장이 기존 Thaw와 충돌하지 않아야 한다.

## 진행 기록

- 소스 조사: macOS 27 구현은 development가 아닌 feat/thaw-3에 있어 이 브랜치를 선택했다.
- 전체 Xcode와 Swift 6.4가 필요한 소스이며 현재 Swift 6.3.3/Command Line Tools만 있다. 사용자에게 설치 가능 여부를 비동기로 요청했다. 그동안 제품 코드와 독립 테스트를 진행한다.
- 실행 방식은 메인 에이전트 구현 및 마지막 독립 리뷰로 정한다. 사용자가 설계에 따라 진행을 승인했으므로 추가 계획 승인 절차는 생략한다.
- 제품 기본값·식별자 분리, 최소 설정 화면, 로그인 최초 초기화, 5초 연속 유휴 타이머, 로컬 빌드/테스트 스크립트를 구현했다.
- 독립 리뷰에서 발견한 기존 Thaw 프로필 자동 적용 문제를 수정하고 재검토했다. 조치 필요 문제 없음.
- 정책 테스트 5개 및 전체 SwiftLint, 변경 소스 구문 검사, plist 검사를 통과했다. 상세 기록은 `docs/verification.md`.
- 사용자 Xcode 27.1 설치 후 Release 빌드·서명 검증을 완료했다. `/Applications/Neat.app` 설치 후 권한 안내창까지 확인했다.
- 네이티브 테스트 빌드에서 기존 ThawAXCore 중복 정적 연결과 ThawConcurrency 직접 연결 누락을 수정했다. 독립 리뷰 재검토를 통과했으며 선택한 네이티브 회귀 테스트 15건을 통과했다.
- 실제 메뉴바 조작 검증은 사용자 권한 승인 후 진행할 수 있다. 전체 테스트·외부 모니터 검증은 아직 완료하지 않았다.
