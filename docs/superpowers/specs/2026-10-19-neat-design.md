# Neat 구현 명세

## 목적과 기반

개인용 MacBook 메뉴 막대 정리 앱을 만든다. 노치 때문에 보이지 않는 항목을 별도 바에서 사용할 수 있게 한다. 이름은 Neat이며, 현재 사용 환경인 macOS 27.0.1(26A434), Apple Silicon을 기준으로 빌드하고 검증한다.

사용자는 Thaw 기반으로 필요한 기능만 남기도록 선택했다. macOS 27을 지원하는 Thaw 소스를 고정된 커밋으로 가져와 기존 메뉴 막대 제어, 원본 항목 클릭, 설정 저장, 화면 대응을 재사용한다. 원본 GPL-3.0 라이선스와 저작권 고지는 보존한다. 해당 소스 버전의 빌드 요구 사항과 사용 가능한 도구를 조사하고 필요한 최소 환경을 맞춘다. 현재는 Command Line Tools와 Swift 6.3.3만 확인했으며, 전체 Xcode 설치 여부와 빌드 가능성은 미확인이다.

## 확정한 사용자 동작

1. 설정창에 보임과 숨김 두 영역을 둔다. 아이콘을 드래그해 영역과 순서를 변경한다.
2. 평소 실제 메뉴 막대에는 보임 항목만 표시한다. 처음 발견한 항목은 보임에 둔다. 분류와 순서는 앱 재실행 후 복원한다.
3. Neat 메뉴 막대 아이콘 또는 메뉴 막대의 빈 공간을 클릭하면, 메뉴 막대 아래에 숨김 항목을 담은 가로 바를 연다. 같은 트리거로 다시 클릭하면 닫는다. 기존 앱 아이콘이나 앱 메뉴 클릭을 빈 공간 클릭으로 취급하지 않는다.
4. 숨김 바의 아이콘은 실제 원본 항목을 작동시킨다. 원본 메뉴를 조작하는 동안 바깥 클릭이나 타이머 처리 때문에 해당 메뉴를 강제로 닫지 않는다. 원본 항목을 잠시 노출해야 하는 경우 Thaw의 기존 처리와 복원 로직을 사용한다.
5. 바와 그 바에서 연 원본 메뉴의 조작 영역 밖을 클릭하면 바를 닫는다.
6. 설정에 5초 자동 닫기 켜기/끄기를 둔다. 켜면 마지막 조작 이후 사용하지 않는 동안 5초가 지나면 닫는다. 포인터가 바 또는 메뉴 막대 위에 있거나 원본 메뉴를 사용하는 동안에는 닫지 않으며 사용이 끝나면 다시 5초를 기다린다. 시간 자체를 변경하는 옵션은 넣지 않는다.
7. 외부 모니터를 지원한다. 화면별 저장과 활성 메뉴 막대 처리는 Thaw를 따른다. 화면 연결과 해제 시 표시 영역과 원본 클릭 좌표를 갱신한다.
8. 로그인 시 실행을 설정에서 켜고 끌 수 있으며 첫 실행 기본값은 켜짐이다. 이후에는 사용자가 선택한 값을 보존한다.
9. 사용자는 손쉬운 사용과 화면 캡처 권한을 허용했다. 실제 macOS 권한 부여는 시스템 UI를 통해 사용자가 수행하며 앱은 필요한 안내와 상태를 표시한다. macOS 27에서 추가 시스템 권한이 필요하면 기존 Thaw의 안내와 상태 처리를 유지한다.

## 화면과 최소 범위

outline/image-1.png의 반투명 가로 바와 outline/image-2.png의 보임/숨김 두 줄 배치를 참고한다. 한국어 UI, 네이티브 macOS 컨트롤, 둥근 모서리와 명확한 드래그 대상을 사용한다. Neat 아이콘에서 설정과 종료에 접근할 수 있어야 한다.

설정은 보임/숨김 배치, 5초 자동 닫기, 로그인 시 실행, 필요한 권한 상태와 안내만 제공한다. 사용자에게 필요한 기능만 노출하되, 핵심 동작이 의존하는 Thaw 내부 구현은 무리하게 제거하지 않는다. 검색, 프로필, 조건별 자동화, 테마 편집, 항상 숨김 분류, 단축키 편집, 자동 업데이트는 초기 제품 범위에서 제외한다. 외부 배포, App Store 등록, 유료 개발자 서명과 공증은 이번 작업 범위에 포함하지 않는다.

## 구현자가 정한 세부값

- 자동 닫기의 첫 실행 기본값은 꺼짐으로 한다. 켜면 5초로 고정한다.
- 바는 클릭한 화면의 메뉴 막대 아래, 화면 밖으로 나가지 않는 위치에 표시한다. 여러 화면에 동시에 복제하지 않는다.
- 고정된 시스템 항목 등 macOS가 이동을 허용하지 않는 항목은 기존 Thaw 제한을 따른다. 이동 가능한 것처럼 표시하거나 성공으로 처리하지 않는다.
- Thaw의 타이머가 주기 검사 기반이라면 요구한 마지막 조작 기준과 맞는지 검토하고 필요한 부분만 조정한다.
- 네트워크에 의존하는 업데이트 확인 등 불필요한 시작 동작은 끈다.

## 완료 기준과 검증

- 현재 맥에서 실행 가능한 Neat.app과 재현 가능한 빌드/실행 안내를 제공한다.
- 보임/숨김 이동과 재시작 복원, 새 항목의 보임 기본값을 검증한다.
- 두 종류의 열기 트리거, 바깥 클릭 닫기, 5초 유휴 닫기 및 메뉴 조작 보호를 검증한다.
- 로그인 시 실행의 첫 실행 기본값과 이후 사용자 선택 보존을 확인한다.
- 외부 화면에 접근 가능하면 연결/해제 및 각 화면 클릭을 실제 검증한다. 하드웨어가 없으면 미검증 사실을 명시한다.
- 새로 추가하거나 변경한 비자명한 로직에는 적절한 작은 테스트를 남기고, 기존 관련 테스트와 빌드를 수행한다.
- 기능 변경 후 개발 대화를 전달하지 않은 별도 리뷰 에이전트로 정확성, 회귀, 보안을 검토한다. 실제 문제를 고친 뒤 관련 검증을 다시 수행한다.
- 권한 대화상자나 하드웨어 때문에 검증하지 못한 부분을 구현 완료와 구분해 보고한다.
