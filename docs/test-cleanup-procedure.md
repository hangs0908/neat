# 테스트 정리 절차

앱 설치·권한·시스템 등록을 변경하거나 임시 키체인·tap 등 별도 자원을 생성하는 테스트에 적용한다. 정리 범위와 기존 사용자 상태 보존 기준은 [AGENTS.md](../AGENTS.md)의 ‘테스트 종료 후 정리’를 따른다.

## 테스트 전 기록

- 생성할 앱 식별자·임시 경로·시스템 등록 항목과 변경 전 사용자 상태를 기록한다. 기존 항목과 이번 테스트에서 생성할 항목을 구분한다.
- 일회성 앱·설치 파일·도구는 작업별 임시 디렉터리에 모은다.

## 테스트 종료 후 정리

아래 절차는 이번 테스트에서 생성하거나 변경한 자원에만 적용한다.

1. 테스트 프로세스·서버·테스트 러너를 종료한다.
2. 테스트에서 새로 생성한 로그인 항목과 앱 등록을 제거한다. 새로 생성한 권한 항목은 권한을 끄는 데서 끝내지 않고, 사용한 시스템 설정 범주에서 테스트 앱의 목록 항목까지 제거한다. 기존 등록·권한 항목은 기록한 테스트 전 상태로 복원한다.
3. 테스트 앱과 전용 preferences·캐시·Application Support·HTTPStorages·저장 상태를 제거한다.
4. 기록한 UUID 테스트 설정 plist·임시 키체인·tap·중복 빌드·복제 앱·변조 ZIP·일회성 스크립트가 남아 있는지 확인하고 제거한다.

## 정리 결과 확인

- 변경한 시스템 설정 화면을 다시 열어 새로 생성한 항목의 제거와 기존 항목의 복원을 확인한다.
- 기록한 경로·식별자를 기준으로 파일시스템·프로세스·시스템 등록을 재검사한다.
- 제거 항목·남긴 자료·복원 결과와 검증 근거를 보고한다. 인증이나 도구 제약으로 제거·복원을 확인하지 못한 항목은 차단 사유와 함께 정리 미완료로 보고한다.
