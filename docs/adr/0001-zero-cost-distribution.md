# 배포 비용 0원과 기존 비공개 구성요소 유지

2026-10-21 결정. Neat은 사용자에게 무료로 제공하고 개발자의 추가 배포 비용도 0원으로 유지한다. 유료 Developer Program 가입을 전제로 하지 않으며, 공증 없는 배포에서 사용자가 최초 실행을 개별 허용해야 할 수 있음을 수용한다. 설치 편의보다 비용 제약을 우선한 결정이다.

첫 배포에서는 핵심 기능 대체 개발을 추가하지 않고 비공개 PlatformRuntimeKit을 유지한 채 Neat 앱 소스를 공개한다. 비공개 구성요소의 존재를 명시하며 모든 구성요소가 오픈소스라고 표현하지 않는다. 이 결정은 구성요소의 재배포 조건 확인이나 실제 설치·업데이트 검증을 대신하지 않는다.

최초 설치는 자체 Homebrew tap으로 제공하고, 이후 업데이트는 앱에서 알린 뒤 사용자의 명시적인 설치 선택에 따라 처리한다. 업데이트 파일에는 EdDSA 서명을 적용하지만 Apple 공증을 대체한다고 안내하지 않는다. 첫 배포 대상은 macOS 27 이상·Apple Silicon으로 제한한다.
