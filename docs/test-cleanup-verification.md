# 테스트 잔여물 정리 검증

- 범위: Neat 무료 배포·업데이트 검증에서 만든 두 앱(`local.hangjin.Neat.DistributionTest`, `local.hangjin.Neat.UpdateTest`)과 종료된 테스트 산출물.
- 시스템 설정 실제 조작: 기기 제어 및 데이터 접근에서 두 테스트 앱, 화면 및 시스템 오디오 녹음에서 배포 테스트 앱을 선택해 제거했다. 인증 후 해당 화면을 다시 열어 목록에서 사라졌으며 실제 Neat의 켜진 권한은 유지됨을 확인했다.
- 입력 모니터링·앱 관리·로그인 항목과 백그라운드 앱 목록에는 두 테스트 앱이 없었다. 경로별 LaunchServices 등록 해제와 오래된 등록 정리 후 시스템 설정을 종료하고 다시 열어 알림의 ‘Neat 업데이트 테스트’도 사라졌음을 확인했다.
- 파일 정리: 복제 앱·중복 DerivedData·업데이트 서버와 피드·변조 ZIP·일회성 도구·과거 검증 산출물, 두 테스트 앱의 preferences·Application Support·Caches·HTTPStorages를 제거했다. 프로젝트 테스트 코드의 UUID suite 이름과 대조한 설정 plist 376개도 제거했다.
- 배포 작업 디렉터리의 build 사용량은 6,249,168KiB에서 200,172KiB로 감소했다(약 5.8GiB 회수). 마지막 전체 테스트·원격 CI·정적 검사 로그는 `build/verification/fixes/`에 보존했다.
- 실제 `/Applications/Neat.app`, 사용자 설정·프로필, 배포 서명 키, 현재 0.1.0 배포 후보, 다른 진행 중인 작업의 미커밋 변경·검증 자료와 공유 의존성 캐시는 보존했다.
- 파일시스템 재검사에서 정리한 테스트 설정과 앱 데이터가 없었고, 테스트 실행 프로세스·임시 키체인·테스트 Homebrew tap도 없었다. 두 테스트 식별자의 LaunchServices 등록 부재를 확인했다.
- 이번 변경은 정리 정책 문서만 수정했다. 자동 테스트는 다시 실행하지 않았으며, 정리 검증은 실제 시스템 설정 조작과 파일·프로세스·등록 재검사로 수행했다. 코드 변경과 독립 코드 리뷰 대상은 없다.
