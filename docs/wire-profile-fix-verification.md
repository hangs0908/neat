# AX 프레임·프로필 이름 변경 결함 수정 검증

## 수정 범위

AXWire.read는 선언한 길이만큼 본문을 읽었는지 확인한 뒤 JSON을 디코딩한다. 유효한 JSON으로 끝나는 부분 프레임도 `.truncated` 오류로 거부하며, 정상 프레임·연속 프레임·정상 EOF의 동작은 유지한다.

프로필 이름 변경은 파일과 목록의 저장이 모두 끝난 뒤에만 ProfileManager.profiles를 갱신한다. 목록 저장 실패 시 프로필 파일의 원래 바이트를 복구하고 원래 오류를 전달한다. 복구 자체도 실패하면 두 오류를 포함한 별도 복구 실패 오류를 전달한다. 활성 프로필 식별자는 변경하지 않는다.

ProfileManager의 기존 크기 제한을 늘리지 않도록 이름 변경의 파일 처리만 ProfileRenamer로 옮겼다. 기존 lint baseline의 2개 크기 예외는 줄어든 수치로만 갱신했다(파일 1,214→1,196줄, 클래스 935→919줄). 새 예외나 규칙 억제는 추가하지 않았다. 이름 변경 이외의 CRUD, 파일 형식과 공개 메서드는 변경하지 않았다.

## 회귀 테스트

- AX: 실제 Pipe에 `[0, 0, 0, 2, 49]`를 쓰고 writer를 닫는다. 수정 전에는 오류 없이 Int 1을 반환하여 테스트가 실패했고, 수정 후에는 `.truncated`로 통과한다.
- 프로필: UUID 임시 저장소의 profiles.json 경로를 디렉터리로 바꾸고 이름 변경을 호출한다. 수정 전에는 원본 바이트와 메모리 목록 보존 기대가 실패했다. 수정 후에는 원본 바이트·목록·활성 ID가 유지되고, 저장 경로 복구 후 같은 manager에서 재시도·재로딩이 성공한다.
- 기존 프로필 이름 변경·복제·설정 교체·잘못된 원본·가져오기/내보내기 및 display/Space 연결 테스트도 함께 실행한다.

## 실제 화면 조작

macOS 27.0.1 / Xcode 27.1에서 최신 ProfileSettingsPane과 ProfileManager를 사용하는 임시 네이티브 창을 실행했다. 임시 데이터는 작업 전 기록한 전용 폴더와 suite에만 저장했다. 앱의 일반 부트스트랩이나 프로필 적용·메뉴 막대 이동은 실행하지 않았다.

1. 프로필 행의 More profile actions → 이름 변경을 선택했다.
2. 실제 텍스트 필드에 키보드로 `UI 실패 시도`를 입력하고 Return을 눌렀다.
3. 목록 저장 실패 알림과 `UI 원본` 이름 유지를 확인하고 파일 바이트도 비교했다.
4. 임시 목록 경로를 복구한 뒤 같은 화면에서 `UI 성공`을 키보드로 입력하고 Return을 눌렀다.
5. 목록의 새 이름 표시와 새 manager로 재로딩한 파일·목록의 새 이름을 모두 확인했다.

Swift Testing 호스트 안에서는 SwiftUI 화면이 비어 있어 조작 완료로 계산하지 않았다. 별도 앱 실행 루프에서 같은 프로덕션 화면을 검증했다. 접근성 값 설정만으로는 편집 상태가 반영되지 않아 실제 키보드 입력으로 다시 검증했다. 임시 검증 창·진입점 코드는 최종 소스에서 제거했다.

AXWire는 화면에 직접 노출된 기능이 아니므로 원래 재현 절차인 실제 Pipe 입출력으로 검증했다. 실제 AX helper 프로세스에 잘린 메시지를 주입하거나 사용자 메뉴 막대 아이콘을 조작하지는 않았다.

## 한계

이번 프로필 수정은 실제 재현된 이름 변경 경로와 이를 사용하는 실행 취소 경로를 대상으로 한다. 다른 CRUD의 트랜잭션 정책은 바꾸지 않았다. 두 파일을 쓰는 사이의 프로세스 강제 종료까지 원자적으로 복구하는 저널링은 포함하지 않는다.

## 자동 검증과 리뷰

루트 정책 5개·서명 회귀 3개, AX 패키지 47개 테스트가 통과했다. 프로필 회귀와 기존 연결 테스트도 통과했다. strict SwiftLint는 660파일 위반 0개다. 독립 리뷰는 개발 대화 없이 수행했고 조치 필요한 문제를 발견하지 못했다.

최초 전체 실행에서는 XCODE_RUNNING_FOR_PREVIEWS=1 환경에서 기존 StatusIconNetworkTests의 이미지 렌더링 2개와 SettingsSmallViewsTests/rowLabelDetail이 실패했다. 같은 코드로 previews 플래그를 끄고 AppDelegate 초기화 차단용 XCODE_RUNNING_FOR_PLAYGROUNDS=1을 사용하자, 해당 영역과 프로필을 포함한 23개 테스트가 통과했다. 테스트 기대값이나 프로덕션 동작을 바꾸지 않았다.

최종 전체 재실행은 1,757개 중 1,756개 통과, 실패 0개, 건너뜀 1개였다.

## 사후 정리

초기 설정 파일 목록과 비교해 새 테스트 설정 240개를 식별·삭제하고 잔여 0개를 확인했다. 테스트 전용 bundle 식별자의 권한 기록만 초기화한 뒤 시스템 설정의 접근성·입력 모니터링·화면 녹음 목록을 다시 확인했다. 테스트 앱 항목은 없어졌고 실제 Neat의 접근성·화면 녹음 권한은 유지됐다. 검사를 위해 열었던 시스템 설정 창은 닫았다.

작업용 앱과 내장 앱 등록, 임시 저장소·빌드·도구·검증용 소스·프로파일링 파일과 임시 스크린샷을 제거했다. 사용자 앱과 프로필은 정리 대상에서 제외했으며, 문서·검증 스크린샷 2개·최소 로그만 남겼다.
