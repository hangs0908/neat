# 숨김 바와 5초 자동 닫기

## Sub-features

- Neat 아이콘과 메뉴 막대 빈 공간 각각으로 숨김 바를 연다.
- 숨긴 아이콘에서 원래 앱 메뉴를 열고 닫는다.
- 바깥 클릭과 자동 닫기를 검증한다.
- 포인터가 바 위에 있거나 메뉴 사용 중일 때 바를 유지한다.

## How to get to it (user POV)

실제 메뉴 막대의 Neat 아이콘 또는 빈 공간을 클릭한다. 설정창의 `마지막 조작 이후 5초 뒤 자동으로 닫기`에서 타이머를 설정한다.

## Driving it with CUA

숨김 아이콘이 하나 이상 필요하다. 없으면 준비 실패를 기록하고 배치 지도에 따라 원래 순서를 기록한 뒤 아이콘 하나를 옮긴다.

`cua.getApp('com.apple.systemuiserver')`의 실제 AX와 스크린샷에서 메뉴 막대 타깃이 노출되는지 확인한다. Neat 아이콘과 빈 공간을 각각 클릭하고 매번 Neat의 AX·스크린샷으로 숨김 바 표시를 확인한다. 바의 안전한 아이콘 하나를 클릭해 원래 앱 메뉴가 열리는지 확인하고 Escape로 닫는다. 최신 화면에서 바깥의 안전한 빈 영역을 클릭해 바가 닫히는지 확인한다.

설정창 스위치의 원래 값을 기록한다. 켠 상태에서 바를 열고 포인터를 밖으로 옮긴다. 마지막 조작 시각과 5초 전후 상태를 캡처한다. 바 위와 앱 메뉴가 열린 상태에서는 5초 이상 유지됨을 각각 확인한다. 메뉴를 닫고 포인터를 밖으로 옮긴 시점부터 다시 닫힘을 확인한다. 스위치와 임시 배치를 원복한다.

## Gotchas

메뉴 막대 대상 앱 연결이 timeout이거나 전체 막대를 캡처할 수 없으면 해당 진입점 검증을 중단한다. Neat 설정창 아이콘 클릭으로 대신 통과시키지 않는다. 좌표·아이콘 이름은 사용자 환경에서 직접 읽는다. 메뉴에서 외부 동작을 실행하지 않는다.

타이머 기본값은 꺼짐이다. 현재 사용자 값과 기본값을 혼동하지 않는다. 구현 근거는 `SimpleModeSettingsPane.swift`, `upstream/Thaw/Neat/NeatPolicy.swift`다.
