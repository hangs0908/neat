# 로그인 시 Neat 실행

## Sub-features

- 첫 실행에서 로그인 항목을 활성화한다.
- 사용자 스위치 선택을 재실행 후 유지한다.
- 설정창에 실제 시스템 등록 상태를 표시한다.

## How to get to it (user POV)

설정창 동작 영역의 `로그인 시 Neat 실행` 스위치를 사용한다. 시스템 설정의 로그인 항목에서도 상태를 확인한다.

## Driving it with CUA

먼저 테스트 정리 절차와 원래 스위치·시스템 등록 상태를 기록한다. 최신 AX에서 해당 스위치를 클릭하고 다시 읽는다. 시스템 설정의 실제 로그인 항목 화면에서도 Neat 등록 상태를 확인한다. 승인 대기 상태라면 완료로 계산하지 않는다.

정상 종료·재실행 후 선택이 유지되고 시스템 상태와 일치하는지 확인한다. 같은 UI 경로로 원래 상태를 복원하고 시스템 설정에서도 복원을 확인한다. 첫 실행은 기존 사용자 preferences를 지우지 말고 별도 macOS 사용자 세션에서 검증한다.

## Gotchas

시스템 승인이 필요할 수 있다. 권한·인증을 진행할 수 없으면 차단 사유를 보고한다. 실제 로그아웃·로그인은 현재 세션 작업을 중단하므로 별도 검증 범위로 기록한다. 재실행만으로 로그인 실행을 통과시키지 않는다.

구현 근거는 `Settings/Models/LaunchAtLoginSetting.swift`와 `NeatPolicy.shouldEnableLogin`이다.
